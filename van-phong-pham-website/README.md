# Cửa hàng văn phòng phẩm
**Nơi có vô vàn đồ dùng học tập**. *Từ những chiếc bút mới mẻ,độc lạ đến những quyển vở cho bạn thỏa sức lựa chọn với mức giá rẻ và chất lượng tốt.*
|Thư mục |Nội dung|
|-|-|
|media|Ảnh logo văn phòng phẩm|
|backup|Bản sao logo văn phòng phẩm|
|data| Dữ liệu đơn bán tháng 10|
|docs| Danh sách nhập hàng|
|logs| Dữ liệu truy cập của cửa hàng|
``` sehll
gc -force
```
- [x] Kiểm hàng nhập về
- [x] Kiểm hàng tồn kho
- [ ] Cập nhật danh sách đơn bán trong tháng
> Lưu ý: file `.env` là file chứa dữ liệu mật vì vậy tuyệt đối không upload lên Github.
